自组Nas，搭建属于自己的私人网盘

邢走在云端 2025-01-02 22:22:45 nas

如今的信息化时代，网盘类应用琳琅满目，数不胜数，然而，其下载速度、安全性、隐私性、以及可玩性都很不如意。在2024年年底，我搭建了属于自己的一套nas系统，特于25年年初进行记录。

# 0. 什么是nas，你需要nas么

NAS（Network Attached Storage：网络附加存储），从字面意思来看，就是连接网络，具备数据存储功能的装置。广义上来说，大到企业级专业存储服务器，小到电脑上设置一个共享文件夹，甚至在路由器上插一块U盘，都可以叫做NAS。

那么你需要nas么？ 如果大家从经济上看，nas和网盘对比，nas是不划算的，首先，nas并不能帮我们省去多少网盘费用，相反，购置nas还得花费很大成本，成本主要在硬盘上，这个硬盘还可能损坏。。。

如果你考虑的是安全性或者在家中局域网观影，那么nas真的是一个非常值得投入的产品。

# 1. nas需求

# 1.0 前言

从需求出发，我希望有多个盘，预算有限的情况选择了双盘。

一个盘主要存储重要文件，家人的手机图片和视频，一个盘用于备份和放置大但是不重要的资源，比如电影（从网上也能下载）。

从网上了解到数据的各种备份raid0、raid1、等等方式，我觉得个人和小家庭不需要关注这些，使用基础的basic模式，将重要的主盘数据用定时任务同步到辅盘即可，如果不放心，再准备一个冷备份的盘，隔三岔五进行增量备份。

具体思路如上图，如果某一天：

1、主盘坏了，及时更换主盘，将辅盘的内容还原到主盘。

2、辅盘坏了，及时更换辅盘，将主盘的内容备份到辅盘。

3、主盘辅盘都炸了，更换主盘和辅盘，将外置冷备份盘数据传到主盘，辅盘自动同步。

4、如果主盘、辅盘、外置冷备份盘都炸了，，，😅，那运气也是极差的。那么建议再增加一条备份链，如下图。增加一个云盘的备份链。但是这个安全性就看个人的加密手段了。个人觉的只用主盘辅盘和冷备份就行了。

# 2. 系统

​ 选择了可靠的（黑）群晖系统（7.2.1），行业标杆。考虑过最近新兴的FnOs，国产的一个免费nas系统，鉴于安全性和健壮性，我还是选择了群晖，毕竟主要服务于企业数据，群晖公司已经成立20多年了，要是出啥幺蛾子，其他企业也不能放了他们是吧。

# 2.3 推荐应用

# 2.3.1 群晖相册

用于管理照片

# 2.3.2 jellyfin

用于观影

# 2.3.3 Hyper Backup

定时备份文件，我就是用这个应用从主盘备份应用到辅盘的，他能做到定时备份

# 2.3.4 qBittorrent

用于下载视频

# 2.3.5 webDAV Server

用户将nas文件系统挂载到windows\linux等终端，就和使用普通盘符一样丝滑

# 2.3.6 docker

进入终端安装docker，可以任意拓展你想要的应用

# 2.3.7 frp

用于内网穿透，使用docker安装，在群晖上安装frpc客户端，在你的云服务器上安装frps服务端，然后配置映射，就能在非局域网环境访问你的nas了

# 2.3.8 ddns-go

可以将你的ip6动态绑定域名，不需要借用服务器，只需购买一个域名就行，然后就可以进行内网穿透了。这个需要家庭网络支持ipv6，且光猫开启了桥接模式，采用路由器拨号，开启防火墙，，，这些环境我不具备，但是我有一个5年期的云服务器，所以我才用了frp穿透，相对来说安全些。
